# 群峦精妙背包升级
## 添加了群峦版本的背包及其升级插件
#### 升级插件功能是正常的，只是精妙背包里的物品存在显示问题

### 模组内容
1. 添加了六种背包：铋铜背包、青铜背包、黑铜背包对应精妙背包的铁制背包；锻铁背包对应精妙背包的金制背包；钢制背包对应精妙背包的钻石背包；黑钢对应精妙背包的下界合金背包;
2. 添加了冰箱升级插件，用于在背包保存食物，延长其保质期（在精妙背包内的食物物品存在保质期和食物特性的显示错误，我目前无法解决这个问题。尽管如此，这个插件的功能是正常的！）；
3. 添加了烤炉升级插件，用于在背包内烹饪食物，兼容群峦的加热配方以及FirmaLife的烤炉配方（在精妙背包内的物品存在加热条的显示问题，我目前无法解决这个问题。尽管如此，这个插件的功能是正常的！）；
4. 添加了各金属等级的堆叠升级。

### 原本在计划中的内容 （这个两项因温度显示问题没解决，因此未开始制作）
1. 坩埚升级插件，用于在背包内加热或冶炼金属；
2. 砧升级插件，用于在背包内锻造物品。


# TFC Sophisticated Backpacks Upgrade
## Added backpack and upgrade for TFC
#### The upgrade function is normal, but there is a display question with the items in the sophisticated backpack

### Mod Content
1. Six types of backpacks have been added: Bismuth Bronze Backpack, Bronze Backpack, and Black Bronze Backpack correspond to the Iron Backpack; Wrought Iron Backpack corresponds to the Gold Backpack; Steel Backpack corresponds to the Diamond Backpack; Black Steel corresponds to the Netherite Backpack.
2. Added fridge upgrade to preserve food in the backpack and extend its shelf life. (There is a question in displaying the shelf life and food trait of food items in the sophisticated backpack, which I am currently unable to resolve. Nevertheless, the functionality of this upgrade is normal!)
3. Added oven upgrade to cook food inside the backpack, compatible with the TFC heating recipes and FirmaLife oven recipes. (There is a question with the display of the heating bar for items in the sophisticated backpack, which I am currently unable to resolve. Nevertheless, the functionality of this upgrade is normal!)
4. Added various metal tiers of Stack upgrades.

### Planned Content that Fell Through (Due to the unresolved question with heating bar display)
1. Crucible upgrade, used for heating or smelting metals in the backpack;
2. Anvil upgrade, used for forging items in the backpack.
